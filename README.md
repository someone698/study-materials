# 学习资料分享

计算机学科专业基础综合（408）复习资料，按考点专题整理。

## 目录

| 专题 | 覆盖内容 |
|---|---|
| [虚拟内存](./虚拟内存) | 地址结构与位数拆分、多级页表、TLB、缺页异常、页面置换算法、页框分配与工作集、分段与段页式、虚拟存储 × Cache 交叉 |
| [IO](./IO) | I/O 接口与端口、I/O 指令与特权指令、程序查询／中断／DMA 三种控制方式、中断与异常、外部设备、I/O 软件层次、设备独立性与分配、SPOOLing、缓冲区 |

## 每个专题包含三份文档

| 文件 | 定位 | 用法 |
|---|---|---|
| `<专题>专题.pdf` | 历年真题汇编，按年份编排，含答案与解析 | 按年份刷题 |
| `<专题>知识点.pdf` | 由真题归纳的知识点梳理，每条结论标注出处（年份-题号） | 查漏补缺、记易错点 |
| `<专题>贯通.pdf` | 把考点串成一条完整流程（如「一次访存的全流程」「一次 I/O 请求的全程」），并标记哪些环节真题考过 | 建立整体流程感 |

三者配合使用：先按**专题**刷题，定位自己的薄弱环节；再用**知识点**逐条消化，把易错点坐实；最后用**贯通**把碎片串成完整流程。

## 阅读提示

- `知识点` 中标 ✗ 的说法，是真题里被设成错误选项的表述，属于高频陷阱，值得单独记。
- 每条结论后的「出处：年份-题号」可以直接回真题核对。
- `贯通` 中区分「真题考过」与「课本上有」两类标记，可据此判断优先级。
